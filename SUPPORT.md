# Support

## Usage and implementation questions

Use the issue tracker of the repository that owns the affected behavior. Before opening an issue:

1. read that repository's README and documentation;
2. search existing issues and pull requests;
3. reduce the question to the smallest reproducible case;
4. remove secrets, credentials, personal data, and production data.

Bug reports should use the organization bug form. Capability proposals should use the feature request form.

## Repository ownership

- `0xda-market/0xda-market` owns the provider-agnostic core and market API.
- `0xda-market/0xda-market-bot` owns Telegram client and product interaction behavior.
- `0xda-market/mind` owns organizational architecture, standards, and decisions.
- `0xda-market/.github` owns organization-wide GitHub defaults and the public profile.

## Security

Do not use public support channels for suspected vulnerabilities. Follow [SECURITY.md](SECURITY.md).
